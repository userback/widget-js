# 🐞 Userback Widget for Next.js

Easily integrate [Userback](https://userback.io/) into your Next.js app to collect feedback from users.

---

## ✅ 1. Install and Run

```bash
// install dependencies
yarn install
// run the app
yarn dev
```

## 🔑 2. Update Your Token

Edit the `UserbackProvider.client` file and replace `YOUR_USERBACK_TOKEN` with your Userback token.

## 🌐 3. Add localhost to Allowed Domains
1. Go to your Userback Project
2. Navigate to Settings → Installation
3. Scroll to Allowed Domains
4. Add: `localhost`
